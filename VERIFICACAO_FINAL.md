# Checklist obrigatório antes de enviar a P2

- [ ] Preencher equipe/turma/responsáveis e, se houver, URL do repositório no Caderno de Testes.
- [ ] Executar `npm test` na máquina da equipe e guardar o terminal com os IDs dos casos.
- [ ] Executar e documentar **15 minutos reais** de sessão exploratória, usando `SESSAO_EXPLORATORIA_15MIN.md`.
- [ ] Abrir o site em **dois ambientes**: por exemplo Chromium desktop 1280 x 850 e Chromium mobile 390 x 850; registrar telas e diferenças. Pode executar `python ferramentas/testar_interface.py` em máquina com Playwright e acesso local liberado.
- [ ] Inspecionar os **cinco critérios de usabilidade** também visualmente: rótulos, teclado, foco, mensagens e carrinho vazio.
- [ ] Salvar evidências legíveis com ID dos casos, e adicionar referência no caderno.
- [ ] Atualizar a conclusão e os indicadores do caderno após os testes faltantes.
- [ ] Exportar novamente o DOCX para PDF e incluir PDF atualizado na entrega.
- [ ] Demonstrar na prática os testes, correções, regressão e métricas.

Não marcar como aprovado um caso bloqueado sem executá-lo.
